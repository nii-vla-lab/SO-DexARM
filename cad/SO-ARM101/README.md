# SO-ARM101 arm-body CAD

The files in `step/` and `stl/` are unmodified arm-body parts from TheRobotStudio's official [SO-ARM100 repository](https://github.com/TheRobotStudio/SO-ARM100), revision `7629d2ad9853d10fb903093a33ef6114099d97e5`.

The standard gripper and physical-leader parts are intentionally excluded. For the wrist-roll/pitch part, use [`../Wrist_Roll_Pitch_SO101.step`](../Wrist_Roll_Pitch_SO101.step), which is the SO-DexARM-specific replacement supplied with this project.
